# Security Policy

## Supported Versions

Only the latest version of `convert` receives security updates. Please upgrade
to the latest version before reporting a security issue.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it via GitHub Security
Advisory at https://github.com/Aldo-f/convert/security/advisories/new.

**Do not open a public issue** for security vulnerabilities. We handle all
security reports confidentially and will work with you to coordinate the fix
and public disclosure timeline.

## What to Include

- A description of the vulnerability
- Steps to reproduce the issue
- Affected versions
- Any known mitigations or workarounds
