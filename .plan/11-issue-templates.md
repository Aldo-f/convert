# convert — Issue Templates Plan

## Task: Issue Templates

## Goal
Create standardized issue templates to help users report issues clearly and consistently.

## Scope (IN)
- `bug_report.md` template
- `feature_request.md` template
- `question.md` template
- All templates in `.github/ISSUE_TEMPLATE/` directory

## Scope (OUT)
- Custom issue types beyond these three
- Automated issue processing
- AI-powered issue generation

## TDF Approach
1. Create templates with clear instructions
2. Use clear labels for each template type
3. Make templates simple and actionable

## Acceptance Criteria
- Templates exist in `.github/ISSUE_TEMPLATE/`
- Templates have clear titles and descriptions
- Templates guide users to provide necessary information
- Templates are used by users

## Validation Steps
1. Verify templates exist in correct directory
2. Read each template to ensure it's clear and useful
3. Test that users can create issues using templates

## Dependencies
- GitHub repository structure
- GitHub issue creation interface

## Dependencies NOT included
- Automated issue processing
- AI-powered issue templates
- Community moderation tools

## Implementation Notes
- Use GitHub's built-in issue template feature
- Keep templates short and focused
- Use placeholders for user to fill in
- Include clear instructions at the top of each template
